Accessibility

Last reviewed: 1 January 2026  ·  Standard: WCAG 2.1 AA

Our Commitment

Telco X is committed to making its Service Availability portal accessible to all users, including those with disabilities. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standard across all pages of this portal.

Conformance Status

The Telco X Service Availability portal is partially conformant with WCAG 2.1 AA. Partially conformant means some content does not fully conform to the standard. We are actively working to address known gaps.

Feature Status Notes
Keyboard navigation Supported All interactive elements reachable via Tab and arrow keys
Screen reader support Supported ARIA live regions announce search results and errors
Visible focus indicators Supported 3:1 contrast ratio on all focus outlines
Colour contrast (text) Supported All body text meets 4.5:1 minimum ratio
Touch target size Supported All tap targets are at least 44 × 44 px
RAG status colour-only Supported Status always includes a text label alongside colour
PDF documents In progress Legacy PDFs being remediated for tagged structure

Assistive Technology Tested

This portal has been tested with the following assistive technology combinations:

  • VoiceOver + Safari on macOS and iOS
  • NVDA + Chrome on Windows
  • JAWS + Firefox on Windows
  • TalkBack + Chrome on Android

Known Issues

We are currently aware of the following accessibility issues and are working to resolve them in an upcoming release:

  • Map embed on the result page does not yet have a text alternative describing the pin location
  • Some legacy PDF fact sheets lack tagged headings for navigation

Feedback and Contact

If you experience an accessibility barrier on any part of this portal, we want to hear from you. Please contact us with a description of the issue and the page you were on, and we will respond within 5 business days.
